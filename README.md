# RaVF · NeurIPS 2026

Project page for **RaVF: Learning Radar Velocity Fields via Spatial-Doppler Guidance**, built with Vue 3 and Vite.

## Development

Requires Node.js 22.12+.

```bash
npm ci
npm run dev
```

```bash
npm run build
npm run preview
```

Development serves `/`; the production build and preview use `/RaVF/`.
